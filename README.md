# 星动 Joy · AI 体感颈椎健康游戏

京东黑马 Hackathon 项目 · 用摄像头 + AI 让办公室久坐人群做颈椎微理疗。

## 快速开始（给队友）

**1. 拉代码到本地**
```bash
git clone https://github.com/13811450170-eng/jintianbuditou.git
cd jintianbuditou
```

**2. 起本地服务**（摄像头需要安全上下文，直接双击 index.html 打不开摄像头）
```bash
python3 -m http.server 8000
```
然后浏览器打开 `http://localhost:8000`

**3. 可选参数**
- `http://localhost:8000/?debug=1` 打开实时角度调试面板

## 玩法

颈部锻炼分三段：转头 → 抬头低头 → 侧屈，每段 4 个目标，中间有回正休息。
- 慢而稳才得分（护颈）
- 保持 ~2.5 秒才收集（避免快速甩头）
- 到达最大幅度时 Joy 会转圈庆祝
